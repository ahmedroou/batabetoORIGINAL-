# **App Name**: Deep Dive: The Friendship Game

## Core Features:

- Category Selection: Display the available question categories (Emotional, Tastes, Funny, People, Personal, Game-Style).
- Question Display: Display questions from the selected category in a clean, readable format.
- Player Roles: Allow one player to be the 'answerer' and other players to be the 'guessers'.
- Scoring: Implement a simple scoring system to track correct guesses.
- AI Question Generator: Employ an AI tool to generate additional questions based on the chosen category and the format: "What's your [emotion/food/habit/personality]-related preference?".
- Hidden guess capture: UI component that enables all 'guesser' players to register their guess, visible only to the administrator (or answerer) player, hidden from other guessers
- Show result: Show result to the guessing players

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to evoke emotion and depth.
- Background color: Light gray (#ECEFF1), nearly white, to keep the emphasis on the questions.
- Accent color: Blue (#3F51B5), a slightly different hue from the primary purple, used sparingly for active UI elements such as buttons.
- Body and headline font: 'Inter' (sans-serif) for a modern, readable feel.
- Simple, clear icons to represent each question category (e.g., a heart for 'Emotional', a fork and knife for 'Tastes').
- Clean and straightforward layout with clear separation of questions and options, with enough spacing to reduce any feeling of pressure.
- Subtle animations and transitions, like a fade-in effect for new questions.
